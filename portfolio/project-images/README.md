# Project images

Add project screenshots to this folder using these exact file names:

- `easyrent.jpg`
- `concurrent-orders.jpg`
- `bookstore.jpg`
- `factnli.jpg`
- `clothing-store.jpg`

Recommended format: JPG, 1200 × 800 pixels (3:2), optimized for the web.
If an image is missing, the portfolio automatically displays the project's fallback icon.
